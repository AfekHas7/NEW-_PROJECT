# AuditPilot — startup-3 Validation Summary

**שירות AI-native להכנה למבדקי ISO 9001 · ישראל-first → גלובלי · 2026-05-31**
**Verdict: CONDITIONAL GO · Score 6.1/10** (Planny 6.4 · startup-2 4.3)

---

## Overview (פסקה אחת)
AuditPilot היא חברת שירות מבוססת-AI שמחליפה את יועץ האיכות בהכנת חברות למבדק ISO 9001: ה-AI מבצע את ניתוח הפערים, מייצר את כל מערכת ה-QMS (מדריך איכות, נהלים, הוראות עבודה, תבניות רשומות) ומנהל את תוכנית העבודה עד יום המבדק, בעוד מומחה איכות (אביו של המייסד, שותף-אקוויטי) מפקח ומאשר בנקודות קריטיות בלבד — כך שמומחה אחד מטפל בעשרות לקוחות. המודל בנוי על ה-thesis של YC RFS ("AI-Native Service Companies": למכור את התוצר, לא כלי), עם wedge רכישה של הסמכה ראשונה (~חצי ממחיר היועץ, פחות מחצי מהזמן) ו**אנונת תחזוקה שנתית (surveillance/recert)** שהופכת עסקה חד-פעמית לקשר רב-שנתי.

## Key Findings (מהמחקר — 15 agents, Deep tier)
- **Existential נפתר חיובית:** המודל **לא** regulation-killed — אין כלל נגד מסמכי AI/צד-שלישי; הקו הקשה היחיד = impartiality (preparer≠certifier). **אבל** הערך חייב להיות "ניהול יישום שמייצר רשומות אמיתיות", לא "ייצור מסמכים" (Stage 2 בודק פעולה בפועל).
- **Whitespace אמיתי:** כל ה-incumbents הממומנים (Vanta $4.15B, Drata, Delve $32M) מתעלמים מ-ISO 9001; **אפס יועצי 9001 ישראלים משתמשים ב-AI**.
- **מודל עסקי חזק:** ACVs מתועדים ($6-8K first-time, $1-3K/yr maintenance), WTP מאומת, **5yr LTV ~$10,700/logo** — מתקן את חולשת ה-LTV של שני הקודמים.
- **TAM גלובלי $5-6B/yr**, SAM ישראלי קטן ($5-7M), Y1 SOM ~$130-270K, Y3 base ~$700K.
- **אין moat טכני** — מודל copyable (YC pattern), window רך 12-18ח', Scytale/AuditsReady צעד אחד.

## Strategic Positioning
**"שירות הכנה למבדק ISO מבוסס-AI"** (לא תוכנת QMS, לא יועץ) — done-for-you מלא, בעברית, עם מומחה named+accountable ו-audit guarantee, ממוקד יצרנים ישראליים שנדחפו ל-9001 ע"י מכרזים. ה-onliness composite (vertical+locale+model+expert+guarantee) אמיתי אך copyable → defensibility = execution speed + distribution ישראלי + data flywheel.

## Top 3 Risks + מיטיגציה
1. **מנוף מומחה לא-מאומת (existential כלכלי)** — אם 25-40h/לקוח במקום 8-15h, ה-thesis קורס (טעות startup-2). → **POC לפני בנייה (ניסוי 3); kill ב->20h.**
2. **אין moat טכני, window רך** — Scytale/AuditsReady/Vanta MSP. → speed + distribution moat (רשת האב, primes) + data flywheel.
3. **FMF שאול מהאב (single-point-of-dependency)** — → הסכם אקוויטי + התחייבות + תיעוד ידע→system; גיוס מומחה 2 ב-Y2.

## Confidence Dashboard (what we know vs guess)
- **Solid (Tier 1):** קבילות רגולטורית, whitespace, ACVs, רוויזיית ספט' 2026, TAM גלובלי.
- **Thin ice:** מנוף-מומחה (modeled), SAM/תמחור/קול ישראלי (proxy/inferred), maintenance attach, זרימת לידים. **5 הנחות existential untested.**

## Anti-Patterns Detected
- 🟡 **trend/solution-first impulse** (ה-thesis מ-YC RFS, לא מ-pain שהמייסד חי) — מרוכך: האב חי את הכאב + המחקר אימת.
- 🟡 **unit-economics assumption** (מנוף-מומחה) — ה-blind spot שהפיל את startup-2; כאן **מזוהה ומתועל ל-POC+kill-criterion** (מזוהה ≠ נפתר).
- 🟢 אין boiling-the-ocean / premature-scaling / vanity-metrics / stealth.
